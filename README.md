## 🇬🇧 English

### 🌌 Overview
**Orbit** is a minimal, interactive web experience designed to help you make decisions. Simply type a question, and let the cosmos (powered by the **Yes/No API**) decide your fate with a definitive answer and a matching GIF.

It features a calming, starry background animation and a clean interface.

### ✨ Features
* **Instant Answers:** Get a "YES" or "NO" response instantly.
* **Visual Feedback:** Each answer comes with a fun, random GIF from [yesno.wtf](https://yesno.wtf/).
* **Atmospheric Design:** Custom CSS animations create a floating starfield effect.
* **Zero Dependencies:** No frameworks, no build steps—just pure web technologies.

### 🛠️ Tech Stack
* **HTML5**
* **CSS3**
* **Vanilla JavaScript**

### 🚀 How to Run
You don't need to install anything!

1.  **Online:** [Click here to launch Orbit](https://kdpshehe.github.io/Orbit/) 🚀
2.  **Locally:**
    * Clone or download this repository.
    * Open `index.html` directly in your browser (Double-click or `File → Open`).

### 📂 File Structure
* `index.html` — The main structure of the page.
* `main.css` — Styling, including the responsive layout and star animations.
* `main.js` — Logic for fetching data from the API and generating the background stars.
* `/assets` — Images and icons.

## 🇺🇦 Українська

### 🌌 Огляд
**Orbit** — це мінімалістичний інтерактивний простір для прийняття рішень. Просто напиши своє питання, і космос (за підтримки **Yes/No API**) вирішить твою долю, надавши чітку відповідь та тематичну GIF-анімацію.

Сайт має заспокійливий фон із зоряною анімацією та легкий інтерфейс.

### ✨ Особливості
* **Миттєві відповіді:** Отримуй "YES" або "NO" за лічені секунди.
* **Візуалізація:** Кожна відповідь супроводжується випадковою GIF з [yesno.wtf](https://yesno.wtf/).
* **Атмосферний дизайн:** Кастомна CSS-анімація створює ефект польоту крізь зірки.
* **Легкість:** Жодних фреймворків чи складних налаштувань — тільки чистий код.

### 🛠️ Технології
* **HTML5**
* **CSS3**
* **Vanilla JavaScript**

### 🚀 Як запустити
Встановлювати нічого не потрібно!

1.  **Онлайн:** [Перейти на сайт Orbit](https://kdpshehe.github.io/Orbit/) 🚀
2.  **Локально:**
    * Завантажте цей репозиторій.
    * Відкрийте файл `index.html` у будь-якому браузері.

### 📂 Структура файлів
* `index.html` — Основна розмітка сторінки.
* `main.css` — Стилі, включаючи адаптивність та анімацію зірок.
* `main.js` — Логіка запитів до API та генерація фону.
